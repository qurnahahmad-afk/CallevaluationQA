========== Glossary ==========
R1: Section  | Attribute  | Glossary 
R2: Call Opening  | Was the call opening was clear & within the onset time without distractions (5 seconds) | Agent should be ready to take the call.
Headset and mic should be always in place. 
Agent should be seated in a quite area where he shouldn’t be distracted.
The call should be answered within 5 seconds. 
R3:  | Personalized the Greeting ( Company name - Agent name) | The greeting should be mentioned in full mentioning the following details ( Thank you for calling(Brand Name), (Agent name)is speaking
R4:  | Assistance offered through using phrases (Example How May I Help you , How can I assist you) | Assistance should be offered during the greeting example: How can I help you, How may I assist you
R5: Verfication  | Verfiy customer phone number / member ID number/ order number whenever needed  | Agent need to confirm the phone number or order number in order to verfiy customer profile, for Shukran email or DOB will be required to verfiy any change in customer account 
R6: Telephone Etiquettes | Did the agent assure help  | Assuring help after customer mentioning his/her concern by saying sure I will do my best to help you , of course I will try to check all possible reasons to help you 
R7:  | Asking relevant or logical questions to identify customer concern (probing)/paraphrasing | Probing should be done using open ended questions like could you tell me more about your order or what happened exactly /Agent need to paraphrase customer inqury to ensure that we are aligned with the customer request 
R8:  | the tone voice was matching the customer enthusiasm and or excitement ( Voice Impact) | Agent tone of voice should be smiley and match the customer tone of voice, sleepy/negative/ monotonous tone of voice will
R9:  | build a good rapport with the customer using empathy or good response  | Building rapport must be done by using smiley tone of voice 
showing empathy/ good response should be done immediately by apologizing to the customer when needed or reflect his emotions 
R10:  | addressed the customer by using his/her name with the appropriate title (Except KSA) | Using customer name during the call at least 3 times depend on the call duration(beginning of the call , middle of the call& end of the call)
R11:  | speak with the customer in proper language/ style/negative words  | Agent should use same language that customer using and to avoid ordering language or negative words 
R12:  | Call Duration was aligned with the customer request  | Call duration should be matching the call scenario not too long and not too short 
R13:  | Did the agent focused on the customer request without missing or requesting repeating his query  | Focus with the customer inquries without missing any of it or requesting the customer to repeat it ( Lack of focus)
R14:  | Agent did not interrupt / speak over the customer "Clipping" | Agent should wait for the customer to complete his sentence without interoution or asking the customer to stop talking in order for him to speak 
R15:  | Did the agent showed confidence or expertise in providing infromation to the customer  | agent should be easy to be understood by using structured and organized manner to explain things to customer 
R16:  | Did the agent use slangs/jargons | Using any slang word like ( Ok, yea, Nop, Wanna , Gonna) or Jargons like internal words  ( WWD,FD, etc.) is not allowed 
R17: Hold & transfer protocol | informed the customer with the held activities during the call ( Dead air) | Dead Air should not exceed 30 sec max per pause and will be scored based on the call duration , agent should engage the customer with the activites to avoid the dead air 
R18:  | Did the agent follow the correct hold protocol | the Hold script should be used for placing the call on hold and it should not exceed 2 mins per hold ( May I place the call on hold for 2 mins in order to check more information for you ) 
R19:  | Did the agent follow the correct call transfer protocol | in case required , call should be transferred warmly where the agent need to inform the BO agent or team leader about the customer problem then need to provide the customer with name of the person who will take over the call 
R20:  | Using Mute instead of Hold | Mute is not allowed during the call for any reason, in case the agent need any assiatnce , they can use the hold 
R21: Call Closing | Did the agent offer the customer further assistance  | Agent should offer any further assistance to the customer even if the customer asked for any inquiry , customer should be offered further assistance again 
R22:  | Did the Agent promote the C-Sat survey | C-sat is mandatory to be mentioned by end of each call unless the customer has not been served due to system issue 
R23:  | Did the Agent promote self service/ app download  | Agent to promote the app or guide the customer of any self service that he can do using the mobile app / offer the customer to download the app for better expiernce 
R24:  | Did the Agent recap and close the call properly  | Call closure should be branded and to include a recap for the case resolution 
R25: Process  | Did the agent gather the right information needed to check customer request | Agent should check the customer history and if the same case escalated before also collect from the customer any related information in case he called before 
R26:  | Did the agent checked any related tickets/notes/child ticket for customer issue in case any | Any feedback that has been provide on any previous tickets agent should use it and inform the customer about it , also in case any reply that should be gathered from the customer to update the ticket it should be done as well 
R27:  | Did the agent offered/ Suggested all reasonable alternatives to fulfil customer's needs  | Any feedback that has been provide on any previous tickets agent should use it and inform the customer about it , also in case any reply that should be gathered from the customer to update the ticket it should be done as well 
R28:  | Did the agent take ownership by set caller expection on time frame, process , etc. | agents to provide the customer with the time frame /Proecess resolution time 
R29: Documention  | Did the agent dispose the call correctly  | ticket disposition must be correct with full notes
R30:  | Ticket remarks need to be added clearly by agent in case of new ticket or private note. | Ticekt remerks should represent the issue of the customer with the clear action that needs to be taken 
R31:  | Did the agent create a new ticket rather than updating the existing ticket. | Agent must avoid creating a new ticekt since another old ticekt is opened, and he needs to add a private note about the customer follow up 
R32: Auto Fail | Did the agent offered/ Suggested all reasonable alternatives to fulfil customer's needs  | Agent need to provide the customer with all the possible resolutions if any as well as guiding or educating the customer about the next steps 
R33:  | Did the Agent mislead the customer or used deceptive conduct | Agent should provide the customer with all the correct information related to his query ( refund timeline, return processed.) falling to provide all related information will be considered as misleading the customer 
R34:  | Did the agent create the right ticket on FD/Did the agent follow the correct escalation process  | Correct escalation needs to be done, as per the scenario to the relevant team with all the correct details. 
In case if issue needs to be raised agent should raise it to the concerned team
R35:  | Has the agent behavior was falling under Misrepresentation ( Yelling, screaming, rudeness & sarcasm)  | Any misbehavior showed by the agent( rudeness, Screaming , yelling or sarcasm ) is not allowed and will be falling under Zero tolerance policy
R36:  | Call Avoidance ( Delayed call opening , disconnecting the calls )  | any delay on call openeing will be consider as avoiding calls as well as disconeecting the call/using system issue verbiage without a confirmation by TL will be considered as call avoidance
